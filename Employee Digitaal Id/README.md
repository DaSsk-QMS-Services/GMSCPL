Built with HTML, CSS and vanilla JavaScript. `assets/js/data.js` is the only file you edit to add or change an employee. Then run:

```bash
node tools/build.mjs
```

That rewrites each card, the directory, search filters, the registration block and `sitemap.xml`.

The directory supports search and filters (designation and resident state). Each card has Call, WhatsApp, Email, Save Contact, Navigate, Visit Website, Share, and **Download PDF** (the browser print dialog — choose Save as PDF). The PDF uses the same employee and company fields shown on the card.

Working hours and a company brochure were not on the supplied documents, so they are not invented here. Social profiles other than www.gmscpl.com are omitted for the same reason.
